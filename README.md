Key Features

- Dual Bake Modes: Switch between High-to-Low poly normal map baking and multi-material PBR channel baking.
- Comprehensive PBR Support: Easily bake Albedo, Roughness, Metallic, Normal (OpenGL & DirectX), Specular, Transmission, Subsurface, Alpha, Emission, AO, and Displacement.
- Channel Packing: Pack custom channel configurations or standard presets (ORM, RMA) directly into single RGB/RGBA textures using NumPy.
- Quality & Performance: Includes 2x Supersampling anti-aliasing, automatic Cycles denoising, and an integrated Compositor OIDN post-pass for ultra-clean light maps.
- Automatic Material Setup: Re-apply baked maps to your objects with a single click.
- High-Contrast Color ID Generator: Generate crisp Material/Color ID maps for texturing workflows.
